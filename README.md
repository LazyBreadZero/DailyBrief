# Frontier Intelligence

A daily personal intelligence briefing on **NeuroTech, XR/AR/VR, BCI, spatial computing, and immersive human-experience technology**, written in Economist/FT broadsheet style and delivered by email every morning at **08:00 Europe/Vienna**.

The briefing is generated by a scheduled **Claude Code Routine** that builds on every previous edition via a persistent memory file, so each day's edition references and follows up on earlier ones.

## How it works

1. The routine reads [`briefing_system_prompt.md`](./briefing_system_prompt.md) — the generator instructions and house style.
2. It reads [`briefing_archive.md`](./briefing_archive.md) fully — the **compact active working memory** (open follow-up threads, covered-story dedup index, known vocabulary, action tracker, summary table). The full per-edition record lives separately in [`briefing_archive_detail.md`](./briefing_archive_detail.md), which is *not* read in full — keeping the daily read cost bounded as editions accumulate.
3. It runs 5–8 targeted web searches, prioritising open follow-up threads, then fresh news — fetching full sources for depth.
4. It writes a complete self-contained HTML briefing into [`briefings/`](./briefings) as `YYYY-MM-DD.html`.
5. It appends the full edition block to the cold log and updates the compact sections of `briefing_archive.md` in place (adding new threads, **pruning resolved ones**), keeping active memory lean.
6. It emails the HTML to the recipient.

## Files

| File | Purpose |
|------|---------|
| `briefing_system_prompt.md` | Generator instructions + Economist/FT house style. The routine reads this first. |
| `briefing_archive.md` | **Active working memory** — compact, bounded. Read in full every run; updated in place (new threads added, resolved ones pruned). |
| `briefing_archive_detail.md` | **Cold log** — append-only full per-edition record. Not read in full; consulted one block at a time only when an exact detail is needed. |
| `briefings/` | Output directory — one HTML file per edition. |
| `ROUTINE_SETUP.md` | Copy-paste configuration + click-path for creating the daily Claude Code Routine. |

## Setting up the daily automation

The scheduled routine is created once, by hand, in the Claude Code web/app UI (it cannot be created programmatically). See **[`ROUTINE_SETUP.md`](./ROUTINE_SETUP.md)** for the exact prompt, schedule, connectors, and step-by-step instructions.
