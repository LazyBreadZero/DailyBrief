# Appetite — Routine Setup

> **Appetite now runs as part of the unified daily routine** that produces both briefings in one go. The single source of truth for routine configuration — including the exact Instructions to paste — is **[`../ROUTINE_SETUP.md`](../ROUTINE_SETUP.md)** at the repo root.

This folder still owns everything that makes Appetite *Appetite*:
- `briefing_goal.md` — the mission/why.
- `briefing_system_prompt.md` — house style, the four pillars, the strict email rules.
- `briefing_archive.md` — persistent memory (seeded with Edition 1).
- `email_template.html` — the hardcoded email layout.
- `briefings/` — the published editions.

Recipient: `julinkacannes@gmail.com` · Public URL: `https://lazybreadzero.github.io/DailyBrief/julinka/briefings/<date>.html`

If you ever want Appetite to run as its **own** standalone routine instead, create a new routine pointing at the same repo and use only steps 7–12 from the root `ROUTINE_SETUP.md` (renumbered 1–6).
